Deskripsi: Game open-world bergaya GTA yang mengambil latar Kota Bogor dan sekitarnya dengan visual AAA, cuaca dinamis, aktivitas khas masyarakat Bogor, serta humor lokal.

Notes:
- Dibangun dengan .NET 10 + Rust (low level library - jika diperlukan)
- Optimasi kode dengan best practice, best performance dan efisiensi memory
- Dokumentasi yang lengkap, jelas, mudah dengan dua Bahasa (English dan Bahasa Indonesia)
- Tambahkan screenshot-nya ke readme dan docs
- Tambahkan info pada dokumentasi dan aplikasi: Dibuat oleh Ariana Mischa Fadhila dari Syubadubin Studios  
- PLAN.md untuk roadmap pengembangan, dan Progress.md untuk tracking development
- UI UX-nya yang keren dan professional dibantu dengan skill 'frontend-design' 
- Untuk sculpting, rigging, animating gunakan Blender MCP
- Untuk generate 3D asset, Image dan 2D Art bisa dibantu Rodin MCP
- Jika dibandingkan lebih baik, bisa gunakan alternatif stack pengembangan juga bisa dengan Avalonia UI + ThreeNet (https://github.com/DotNetVibeCoderz/Vibe_Graphics/tree/main/ThreeNet)
